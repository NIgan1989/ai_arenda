# AI Аренда — мобильное приложение

Обновление интерфейса от 22.10.2026: быстрые действия, обзор ближайших событий, прогресс ввода и возврат к вопросу, серверная проверка суммы и интервала до отправки брони. Обновлено: каталог теперь закрыт до входа и выбора роли гостя; ранее он был публичным. [Исследование и общий план](../docs/DESIGN_AUDIT_AND_ROADMAP.md).

Первый нативный клиент на React Native / Expo для Android и iOS. После входа обязателен выбор роли и профиль. Гость, владелец и исполнитель получают отдельные экраны с навигацией. Ассистент сопровождает действия внутри выбранной роли; «Сменить роль» возвращает на выбор. История нового диалога разделена по ролям. Этот же интерфейс открывается в браузере для проверки.

## Запуск на компьютере

Нужен Node.js 24 и npm. Из папки `mobile`:

```sh
npm ci
npm run server
```

В другом терминале, также в `mobile`:

```sh
npm run web
```

Откройте `http://localhost:8081`. Сервер работает на `http://127.0.0.1:8788`. Для веб-просмотра токен живёт только до перезагрузки вкладки: войдите снова, и переписка восстановится с сервера. На телефоне сессия сохраняется в Expo SecureStore. Логин — 3–40 символов латиницей; пароль — от 10 символов. Проверка телефона, восстановление пароля и документы в пилоте не реализованы.

Бизнес-логика собирается из `../lib/service.ts` и `../lib/domain.ts`: календарь и правила уборок общие с веб-версией. База мобильного пилота отдельная, `mobile/data/rental.sqlite`. Она и сессии не входят в Git. Историю нужно резервировать вместе с базой; при живом сервере используйте SQLite Backup API, а не копирование одного файла без WAL. Публикация веб-версии Sites не является сервером этого приложения.

## На телефоне

Установите Expo Go, совместимый с SDK 57. Компьютер и телефон должны быть в одной доверенной Wi-Fi сети. Для теста разрешите локальный порт 8788 в межсетевом экране. В `mobile/.env.local` задайте **адрес компьютера**, например:

```dotenv
EXPO_PUBLIC_API_URL=http://192.168.1.10:8788
```

Это только адрес API, здесь нельзя хранить секретные ключи. Запустите сервер с `HOST=0.0.0.0` (в PowerShell: `$env:HOST='0.0.0.0'; npm run server`), затем `npm start` и откройте QR-код в Expo Go. По умолчанию сервер слушает только этот компьютер. Локальное HTTP-соединение предназначено для проверки с учебными данными. Для внешнего пилота необходим собственный HTTPS API и адрес в `EXPO_PUBLIC_API_URL`.

Нативные JS-пакеты можно проверить командой `npm run export`; это не подписанный APK/IPA. Сборка для установки и публикация в магазинах требуют отдельной настройки подписей и аккаунтов разработчика. На настоящих устройствах приложение пока не проверялось.

## Проверка сценариев

1. Напишите «Покажи учебный пример». Создайте аккаунт и подтвердите добавление учебных данных. Они видны только вашему аккаунту.
2. Выберите квартиру, ответьте на вопросы о датах и подтвердите заявку. Напишите «Заявки гостей», подтвердите её и укажите стоимость уборки. «0» означает подтверждение без создания уборки.
3. Для проверки разных участников используйте отдельные аккаунты: владелец добавляет квартиру фразой «Хочу сдать квартиру», исполнитель — «Хочу работать на уборке», гость — «Хочу снять квартиру». В каждой учётной записи контакт собирается диалогом. Для смены аккаунта напишите «Выйти».
4. Владелец пишет «Создать уборку». Исполнитель находит её через «Найти уборку» и откликается. Владелец открывает «Уборки по квартирам» и назначает исполнителя по анкете. Адрес скрыт до назначения.
5. Исполнитель открывает «Мои задания»: начало работы доступно за час до задания, затем чек-лист и текстовый отчёт. Владелец принимает работу. Оплата согласуется отдельно.
6. «Что нового» показывает события. Пока приложение открыто, обновление запрашивается каждые 15 секунд. Сервер раз в минуту снимает истёкшие резервы и добавляет уведомления о просроченной уборке. Push-уведомления и работа приложения в фоне не реализованы.
7. «Стоп» прерывает незавершённый опрос. После входа сохранённая переписка и опрос восстанавливаются. Отключение сервера не считается успешной заявкой.

## Проверки

```sh
npm run typecheck
npm test
npm run export
```

HTTP-тесты проверяют разные аккаунты, авторизацию, запрет чужих действий, повторную отправку брони, скрытие адресов, назначение исполнителя, восстановление базы после перезапуска и отзыв сессии. Основные проверки календаря и уборки находятся в `../tests/service.test.mjs`.

## Что ещё требуется до запуска бизнеса

Свободная языковая модель не подключена: используются диалоговые сценарии, API языковых моделей не вызывается. Нет реальных платежей, фото, мессенджеров, карт, внешних календарей, восстановления аккаунта, проверки владельцев и исполнителей, договорного найма, push и автоматического подбора замены. Принятый отчёт не означает выплату. Отмеченная владельцем оплата не является банковским подтверждением.

Сервер — однопроцессный пилот на SQLite. Изменения проходят последовательно, SQL-ограничения защищают бронь и назначения. Дополнительно мобильный API проверяет, что отдельная уборка не пересекается с бронью или другой уборкой. Подтверждение из карточки передаёт устойчивый ключ действия: результат и изменение записываются одной транзакцией, поэтому повторная отправка той же карточки не создаёт дубль. Перед публичным использованием нужны HTTPS, подтверждение контактов и модерация, ограничения нагрузки на уровне прокси, мониторинг, резервное восстановление, проверка размещения и обработки данных, публикация политики и подписанные сборки. Гарантировать отсутствие сбоев невозможно. При сбое после записи изменения и до получения ответа сначала обновите карточки; автоматически повторяются только чтения.

Для добавления веб-источников настройте `ALLOWED_ORIGINS` списком URL через запятую. CORS не заменяет токен: каждый запрос к данным требует действующую сессию. Пароли хранятся через scrypt с индивидуальной солью, токены на сервере — только в виде SHA-256; срок сессии семь дней. Секреты OpenAI/банка должны добавляться только на сервере при подключении интеграций.

Тарифы, депозит и готовность: в «Мои квартиры» откройте «Тарифы и готовность». Правила применяются к новым броням; условия сохранённой брони неизменны. В карточке брони владелец подтверждает фактическое получение оплаты/депозита и заселение/освобождение квартиры. Сообщение гостя о выезде требует проверки. Связанная уборка начинается только после подтверждённого выезда. [Авторизация и роли](../docs/AUTHORIZATION_AND_ROLES.md).

Инициативность: в каждой роли откройте «Настройки». Поддерживаются три режима, заблаговременность и тихие часы. Сервер сохраняет параметры по роли; подсказки показываются при открытом приложении. [Полное описание и следующие подключения](../docs/ASSISTANT_SETTINGS.md).
