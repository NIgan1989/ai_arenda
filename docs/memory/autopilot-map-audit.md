2026-11-13 пользователь попросил довести анимацию карты на каждый шаг автопилота у каждой роли и спросил про уход от платных маршрутов. Аудит: https://claude.ai/artifact/Tn2ovFTozqmyBwNx5ZoQCE (копия /mnt/project-files/autopilot-map/). Он утвердил аудит и велел сливать этапы сразу после зелёных проверок, тестовый сайт не делать.

Маршруты: оставить Stadia ($20) до запуска, перед запуском свой Valhalla+Photon ~7–9 €/мес; без согласия не переключать.

Сделано:
- PR #84: `lib/ai-move-marks.ts` (ключи уведомлений ИИ → шаги и подписи), `lib/ai-moves.ts` (aiMarks в map/search), знак ИИ в `components/map-pills.tsx` и `mobile/src/MapPins.tsx`.
- PR #85: журнал «Что сделал ИИ» (aiJournal в GET /api/account; блок в «Тариф и автопилот», строка меню у гостя).
- PR #86: тон alert и движения alarm/calm (ownerPin, cleanerPin), летящая точка при назначении исполнителя, withAiResult, guestPin в `lib/guest-trips.ts`.
- PR #87: брони гостя на карте приложения и «Маршрут» через useTrip('guest') без передачи положения владельцу; правки по замечаниям Codex к #84–#86.
- PR #88 (2026-11-14, main 442cc10): луч подбора гостя начинается в геопозиции гостя или выбранной точке «рядом» (`beamOrigin`; без них луча нет) и идёт по дорогам через `POST /api/operations/map/beam` (`buildBeamRoute`: только Stadia, место гостя округлено до 0,001°, цель — публичная точка жилья). Повод: снимок с iPhone, луч шёл от центра города.
- PR #93 (2026-11-14, main 1951ccf): записи журнала «Что сделал ИИ» нажимаются (уборка, бронь, чат, жильё; `journalHref`, `openEntry` в приложении). Первый вид пользователь назвал некрасивым; принят вид лентой по дням (точка и нить, действие, жильё, кто и когда), одинаково на сайте и в приложении.

Не сделано: «+оплата» у исполнителя после приёмки, опрос карты приложения раз в 10 с при автопилоте, проверка движений на экране (на стенде нет плиток, на бою нет данных).
