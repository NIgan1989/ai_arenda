2026-11-13 пользователь попросил использовать коннектор Limrun для эмуляции. Проверено:
- iOS-симулятор открывает боевой сайт https://ai-arenda.ai-arenda-kz.workers.dev в Safari, карта с настоящей подложкой грузится (в песочнице подложки нет).
- Android-эмулятор ставит настоящее приложение из публичного релиза: https://github.com/NIgan1989/ai_arenda/releases/download/android-latest/ai-arenda.apk (репозиторий публичный). iOS-релиз ios-latest — неподписанный .ipa, для симулятора нужна simulator-сборка .app в zip.
- Эмулятор видит только публичные адреса: локальный стенд песочницы недоступен, туннели (trycloudflare) прокси запрещает.
- На бою нет тестовых учётных записей и объектов (поиск в Павлодаре пуст), поэтому анимации ролей на эмуляторе требуют публичного тестового стенда или демо-аккаунтов. Пользователь 2026-11-13 сказал тестовый сайт не делать, поэтому на эмуляторе проверяется только общий вид, не движения ролей.
- «Обновлена ли мобильная версия?»: сайт — последний запуск «Publish to Cloudflare» (deploy.yml) и его head_sha; приложение — тело релизов android-latest и ios-latest (№ сборки, время, «Исходный код: <sha>»). Сборки APK и IPA идут сами после каждого слияния в main; на телефоне новую сборку надо установить заново.
Удалять экземпляры после снимков (delete-instance). См. [[qa-stand]], [[autopilot-map-audit]].
