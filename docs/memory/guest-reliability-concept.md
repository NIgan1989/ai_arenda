2026-11-16 пользователь спросил, как заменить чёрные списки гостей и сторонние проверки у владельцев. Сделана концепция (Claude Doc): https://claude.ai/artifact/5JyjngorDQpKoQBdfahHNp

Суть: никакого публичного списка с именами. Опора на готовое: lib/reliability.ts (алгоритм 9), lib/booking-risk.ts (алгоритм 8), депозит, фото уборки (job_evidence phase damage). Не хватает приёмки жилья после выезда: владелец не оценивает гостя (stay_reviews только гость → жильё); «checkout_disputed» сейчас значит лишь «не выехал».
Этапы: 1) приёмка после выезда + фото гостя при заселении (можно до юриста); 2) отметки в надёжности + спор гостя 48 ч, срок давности (после юриста и правки оферты); 3) правила владельца + личный запрет «Не принимать гостя»; 4) удержание из депозита по фото; 5) «Надёжный гость» без депозита; 6) проверка личности (после ТОО).
Пользователь 2026-11-16: «можно включить в платный тариф». Предложено: рейтинг, приёмка, спор и личный запрет бесплатны для всех; в «Автопилот» — правила гостей и авторешение, расчёт удержания, сбор приёмки ИИ, сводка ([[autopilot-plans]]).
