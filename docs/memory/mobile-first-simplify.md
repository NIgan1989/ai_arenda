2026-11-14 пользователь: «отныне будем только улучшать мобильную версию для андройда и для айфона». Сайт больше не обязательно менять параллельно, автопилот в приложении может отличаться от веба. Это заменяет прежнее правило «каждое изменение сразу и на сайте, и в приложении» ([[parity-pr96]]).
