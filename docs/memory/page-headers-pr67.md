2026-11-13 пользователь спросил, нужны ли заголовки на всех страницах (чаты, аккаунт, брони, все роли), и попросил убрать лишние. PR #67 https://github.com/NIgan1989/ai_arenda/pull/67, ветка claude/project-thread-t4kglr. Пользователь сказал «сливай»: слит 2026-11-13 (main 5236c3d), публикация в Cloudflare прошла (run 43441486450).

Правило: страница из нижнего меню на телефоне без заголовка (вкладка уже называет её); заголовок остаётся у страниц вне нижнего меню, в мастерах и в открытом чате. Компьютерная версия сайта не менялась.

Сайт: `data-tab` на `.workspace-shell` в `app/chat.tsx`, стили в `app/page-headers.css` (h1 скрыт визуально, кнопки рядом остаются). Приложение: верхняя полоса (название, AI, «⋯») скрыта на вкладках и в профиле (`tabIds` в `mobile/src/WorkspaceNavigation.tsx`); в профиле группа «Разделы» со страницами вне нижнего меню.

Скриншоты: `/mnt/project-files/page-headers/`. Снимки приложения: expo web на 8090 с прокси 8091→5174 без Origin, вход по «+7700000000N», вкладки находить по accessibilityLabel (полное название страницы). См. [[top-bar-pr46]], [[design-system]].
