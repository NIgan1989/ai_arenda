2026-11-13 подготовлены черновики по праву РК, PR #36 https://github.com/NIgan1989/ai_arenda/pull/36 (ветка claude/project-thread-1k5s3r, слит 2026-11-13 по «сливай», main 21d0c0b). Тексты в `lib/legal-documents.ts`, страницы /terms, /terms/guest, /terms/owner, /terms/cleaner, /privacy, /privacy/consent (+ /data-deletion без изменений). Копия для юриста и снимки: /mnt/project-files/legal/ (offers.md).

Пользователь оформляет ИП; после этого доработать остальное. Реквизиты оператора (ИП/ТОО, БИН/ИИН, адрес, почта, телефон, банк) пользователь ещё не дал: поля пустые в `OPERATOR`, на сайте видны жёлтые пропуски. `LEGAL_DRAFT=true` даёт плашку «Проект документа».

Решение пользователя (2026-11-13): никакой налички, все оплаты только через сервис на Kaspi/Halyk. Оферты написаны под агентскую схему: гость платит оператору, тот удерживает 5% («Я сам») или 10% («ИИ») и перечисляет остаток владельцу через 2 рабочих дня после выезда; депозит у оператора, ущерб заявляется в 24 ч с фото; уборка оплачивается исполнителю через сервис. В каждой оферте пункт «до подключения онлайн-оплаты в пилоте» (ручные отметки, комиссия с баланса).

Не сделано: сервер не сохраняет версию принятых документов и время согласия; акцепт оферты владельца/исполнителя при публикации объявления и подключении роли; казахская версия. Юристу проверить: не нужна ли регистрация платёжной организации в НБРК для агентского приёма денег (или сплит-платежи Kaspi/Halyk), локализация ПД в РК (база сейчас у Cloudflare).
