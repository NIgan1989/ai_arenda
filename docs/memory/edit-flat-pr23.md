2026-11-12 пользователь по скриншоту с iPhone попросил: несколько фото разом, значки вместо слов, проще обложка, лучше редактирование. Затем уточнил главное: не одно длинное окно, а каждое действие фиксировать сразу, и чтобы ИИ-администратор предлагал следующий шаг в другом виде, без прокрутки.

Сделано в PR #23 https://github.com/NIgan1989/ai_arenda/pull/23 (ветка claude/project-thread-k4znrw). Слит 2026-11-12 (main b6aac30), опубликован на Cloudflare (run 43308079253).
- Обзор: плитки 2×4, совет ИИ, переключатель «Показывать гостям».
- Каждый шаг открывается на своём экране и сохраняется сразу.
- Общие правила: `lib/listing-edit.ts`.
- Сайт: `components/property-editor.tsx`, `components/photo-grid.tsx`.
- Приложение: `mobile/src/PropertyEdit.tsx`, `mobile/src/PhotoGrid.tsx`.
- В окне над картой заголовок берётся из блока (TaskSheet title), а пока форма открыта, показывается только она (focusMessages в app/chat.tsx).

Проверка при публикации: если включён pilot_policy.require_owner_review, кнопка «Показать гостям» не выдаёт ошибку. Квартира сохраняется черновиком, и создаётся заявка на проверку (reference начинается с PUBLISH_REVIEW). Каждому админу из PLATFORM_ADMIN_IDS приходит уведомление. Когда админ одобряет, квартира публикуется сама, а владельцу приходит уведомление (lib/participant-security.ts).

Скриншоты лежат в /mnt/project-files/edit-flat/. На настоящем телефоне не проверено.

Push: удалённая ветка после squash-слияния хранит старые коммиты, а force-push блокируется. Помогает обычный merge удалённой ветки с выбором своих версий файлов (содержимое там совпадает с main).

См. [[add-flat-pr19]], [[design-system]].

Удаление квартир (PR #25, слит 2026-11-12, main 047c9ce, опубликован вместе с #28 в run 43313758331). Кнопка «Удалить квартиру» внизу редактора. Квартира без истории удаляется целиком, квартира с историей уходит в архив (`properties.archived_at`, миграция 0033, `removeProperty` в lib/service.ts). Если есть будущие брони или незавершённая уборка, удаление отказывает. На стенде миграции сами не применяются, их надо применить к sqlite-файлу стенда через node:sqlite (стенд также отставал на 0032).
