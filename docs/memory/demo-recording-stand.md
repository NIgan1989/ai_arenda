Запись для роликов 2026-11-17 (см. [[investor-video]], [[qa-stand]]). Всё локально, правки в репозиторий не коммитить.
- Стенд: `node scripts/start-browser-qa.mjs` (5174) + CORS-прокси 5175 + `EXPO_PUBLIC_API_URL=http://127.0.0.1:5175 CI=1 npx expo start --web --port 8090 --clear` в mobile/. Metro не видит правок исходников: после правки перезапускать expo. Сессия в превью не переживает перезагрузку страницы.
- Данные: копия seed-browser-qa с именами (Айгерим, Данияр, Сауле, Ерлан, Мадина), шестью объектами в Павлодаре, `requirePhotos:false` (в приложении у исполнителя нет загрузки фото до/после уборки, с правилом отчёт не отправить). Чтобы риск был «низкий»: телефон подтверждён, аккаунт старше, бронь за 3+ часа до заезда. Для инструкции заезда нужен ACCESS_ENCRYPTION_KEY в .dev.vars.
- Время: подмена Date в начале `app/api/[...path]/route.ts` (не в lib/domain.ts, он общий с приложением) и в странице; сдвиг времени требует перезапуска сервера. started_at/submitted_at уборки ставят триггеры SQLite по настоящим часам: триггеры пересоздать со сдвигом.
- Запись: Playwright, запуск chromium с `--force-device-scale-factor=2` и CDP `Page.startScreencast` дают кадры 780×1688; кадры с метками времени склеивает ffmpeg (concat с duration). Плитки карты и фото недоступны из песочницы: подложка схематичная, фото нарисованы.
- Скрывали только в копии для записи: фразы про тестовую оплату и «Банковская операция не выполняется».
- Дополнения 2026-11-18 (скрипты в /mnt/project-files/investor-video/src-v3/stand/, патч demo-stand-local-only.patch там же, на main b4f3fed): вход теперь через кнопку «Войти» на карте (login2.sh). Колесо мыши ломает высоту экрана превью: листать и проводить свайпы только touch-событиями CDP (sw.js, swl.js), а в страницу добавить CSS `html,body,#root{height:844px;overflow:hidden}`. У исполнителя метка «Остановка N» в веб-превью растягивается на весь экран: скрывать CSS. На крупном масштабе плитки карты серые: такие кадры вырезать. После успешного решения в чате остаётся строка «Согласование закрыто или срок истёк»: обрезать клип раньше. Счёт показов: таблица property_views (день = номер суток).
**Why:** Limrun видит только публичные адреса, а демо-аккаунты на боевом сервере пользователь не разрешал.
