2026-11-13 пользователь: «нужно чтобы все действия проходили на нашей карте, если нужно определи карту и я её подключу, не дорогую». Значит не уводить в 2ГИС/Яндекс: навигация, маршрут, своё положение — внутри приложения.

Сейчас: подложка OpenFreeMap (бесплатна, коммерция разрешена, оставить), маршруты — публичный OSRM FOSSGIS routing.openstreetmap.de (только некоммерческий fair use), геокодер — публичный Nominatim (1 запрос/с). Оба надо заменить для коммерции.

Принято: 2026-11-13 пользователь создал ключ и сохранил секрет STADIA_API_KEY в GitHub («все подключил»). Работает с 2026-11-13: публикация main d641c53 (PR #75, починка проверки после #72) сохранила ключ в Worker, в логе шага «Save the map key» — «Stadia Maps key is saved for the Worker.». Маршруты идут через Stadia; геокодер пока публичный Nominatim. Было предложено: Stadia Maps Starter $20/мес, 1 млн кредитов (маршрут 20 кредитов ≈ 50 тыс. маршрутов), коммерция разрешена, Valhalla с манёврами, геокодинг. Сравнение: 2ГИС Routing от 6 700 ₽/мес (+тайлы, геокодер отдельно), GraphHopper Basic 69 €/мес, у бесплатных Stadia/GraphHopper коммерция запрещена.
Пользователь сохраняет ключ в секрете репозитория `STADIA_API_KEY`; ключ только на сервере (Worker), приложение ходит через наш API. Деплой уже переносит TELEGRAM_BOT_TOKEN из секретов GitHub — так же сделать для ключа.
**How to apply:** не добавлять ссылки во внешние навигаторы; ключ в чат не просить. См. [[live-map-concept]].
