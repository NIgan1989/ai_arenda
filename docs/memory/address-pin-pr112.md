2026-11-16 пользователь: поменял город у жилья в приложении, проверка не прошла «нет метки на карте».

Причина: триггер `property_location_address_changed` (drizzle/0020) удаляет метку при смене адреса/города/района, а заново её ставили только после добавления жилья; в приложении поставить метку было негде. Проверка ИИ (`lib/admin-autocheck.ts`) раньше засчитывала любую метку, теперь только совпадающую с адресом (fingerprint city|district|address).

PR #112 (ветка claude/project-thread-zclgxn): `placeQuietly` в lib/participant-security.ts ставит метку по адресу при каждом сохранении жилья и перед проверкой; поиск в lib/map-workspace.ts — варианты адреса (без названия ЖК), Stadia geocoding при STADIA_API_KEY, затем Nominatim; маршрут `operations/map/spot`; `mobile/src/AddressPin.tsx` — карта с меткой в «Адрес», можно сдвинуть; подсказка ИИ «Метки жилья на карте нет» + «Поставить метку». Тесты подменяют fetch геокодера в tests/helpers/platform.mjs. Снимки: /mnt/project-files/address-pin/.

«Нет связи» на скриншоте не связано: полоса появляется, когда запрос к серверу не дошёл (слабая сеть).

Слит и опубликован 2026-11-16 (main af49050, публикация run 43858833251, сборки Android/iPhone № 294 зелёные). На настоящем телефоне не проверено. См. [[edit-flat-pr23]], [[map-provider]], [[property-approval-pr109]].
