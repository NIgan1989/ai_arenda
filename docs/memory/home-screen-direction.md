Первый экран каждой роли (гость, владелец, исполнитель) остаётся картой на весь экран, «как в такси»: снизу одна строка для ИИ, подсказки-чипы и карточка «Сейчас». Отдельную «Главную» без карты пользователь отклонил на карточке выбора 2026-11-12. Постоянный индикатор «Есть связь» пользователь попросил убрать; показывать только сообщение, когда связи нет.

**Why:** пользователь раньше просил интерфейс, «где всё крутится вокруг карты», по модели такси-агрегатора (PR #6), а 2026-11-12 сказал, что главные экраны всех ролей ему не нравятся: цель «простое, но технологичное приложение с ИИ».

**How to apply:** упрощать карту, а не убирать её с первого экрана; не добавлять на карту плашки, степперы и подсказки. Перед изменением прежнего решения пользователя спрашивать одним вопросом. Работа ведётся в ветке claude/project-thread-sjtqme. См. [[design-system]], [[mobile-map-home]].
