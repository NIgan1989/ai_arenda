2026-11-12 пользователь попросил сделать сервис автономным через ИИ-администратора (монетизация — отдельный тред). План в Claude Doc https://claude.ai/artifact/MNXTzgkDK59Aj1m4GRu3yf. Приоритеты: 1) автопилот владельца (сделан); 2) онлайн-оплата + автоприёмка уборки по фото + выплаты (связано с монетизацией); 3) ИИ отвечает на вопросы гостя за владельца, выезд по фото уборщицы, отзывы; 4) ИИ-сводка на странице админа платформы; 5) ИИ составляет объявление и цену; 6) Telegram/SMS.

PR #17 https://github.com/NIgan1989/ai_arenda/pull/17, ветка claude/project-thread-r113az: выбор «Кто отвечает гостям: Выкл / Я сам / ИИ» на квартиру (`lib/autopilot.ts`, `operations/matching/preference` с `mode`). «ИИ» включает matching, auto_confirm, auto_assign, auto_offers, auto_replace; ИИ сразу принимает быстрый запрос гостя после проверки `bookingQuote` (без миграции; ответ только когда квартира в полном режиме «ИИ»). После замечаний Codex добавлены проверка минимальной ставки и автоответ только при полном режиме «ИИ». Слит по «сливай» 2026-11-12 (main 18d2b03), публикация в Cloudflare прошла (run 43286576836). Тесты 320 сайта и 76 приложения прошли; на телефоне и скриншотами не проверено. Следующий шаг плана — онлайн-оплата (пункт 2).
