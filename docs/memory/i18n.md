# Три языка: русский, казахский, английский

2026-11-20 пользователь попросил добавить казахский и английский. Сначала только приложение (сайт остаётся русским: с 2026-11-15 улучшаем только приложение).

## Как устроено
- `lib/i18n.ts`: ключ — русская строка. На экране пишется `t('Войти')`; перевод берётся из таблиц `lib/i18n-*.ts` (строка → [казахский, английский]). Строка без перевода остаётся русской, поэтому переводить можно частями.
- Переменные части в фигурных скобках: `t('Найдено: {n}', {n})`. Слово после числа: `plural(n, [рус. три формы], [англ. две], казахское)`. Предложение со ссылками внутри: `tParts('Принимаю {terms} и даю {consent}')`, у каждого языка свой порядок слов.
- Таблицы названий, созданные один раз при запуске (названия ролей, варианты выбора), оборачиваются в `L({...})`: строки читаются на текущем языке в момент чтения.
- Язык приложения: `mobile/src/lang.ts`. При первом запуске язык телефона (казахский → казахский; русский и языки соседних стран → русский; остальные → английский), потом выбор из меню, он хранится на телефоне. Переключатель `LangSwitch` стоит в меню и на экране входа; названия языков всегда на своём языке.
- Сайт и сервер `setLang` не вызывают, для них всё по-русски. Серверу для текста одному человеку: `tIn('kk', '…')`.
- `node scripts/i18n-missing.mjs [файлы]` печатает строки без перевода. `tests/i18n.test.mjs` проверяет, что в переводах те же переменные.
- Шрифт заголовков Unbounded не имел казахских букв Ә Ғ Қ Ң Ө Ұ Ү Һ. Они дорисованы из его же форм скриптом `scripts/build-kazakh-font.py` (лицензия OFL это разрешает).

## Слова
гость — қонақ — guest; владелец — иесі (иелер) — owner; исполнитель — орындаушы — cleaner; жильё — баспана — place; объект — нысан — property; бронь — бронь — booking; уборка — тазалау — cleaning; заявка — өтінім — request; задание — тапсырма — job; ИИ — ЖИ — AI; ИИ-администратор — ЖИ-әкімші — AI administrator; пароль — құпиясөз; настройки — баптаулар.
Правила те же, что в русском: нейтрально, не «пәтер/квартира», кнопки короткие.

## Решения
- Оферты и политика на казахский и английский не переводятся до проверки юристом. На казахском и английском рядом со ссылками стоит пометка «документы на русском языке»; названия документов переведены.
- Фраза подтверждения удаления аккаунта вводится на языке приложения, серверу уходит русская.

## Этапы
1. Основа, переключатель, заставка, вход, выбор роли, меню, профиль, «Данные и безопасность» — PR этапа 1 (2026-11-20).
2. Гость: карта и поиск, результаты, карточка жилья, бронь, оплата.
3. Владелец: объекты, заявки, уборки, автопилот, доходы.
4. Исполнитель: предложения, уборка, отчёт.
5. Сервер: оповещения в Telegram, сообщения об ошибках, ответы ИИ-администратора на выбранном языке (язык хранить у пользователя).
Пока этапы 2–5 не сделаны, на казахском и английском часть экранов остаётся русской.
