Стенд: `npm install`, `node scripts/start-browser-qa.mjs`, один POST на /api/auth/login создаёт базу, затем три seed-скрипта. Вход ограничен (429 на 15 минут): сохранять сессию (storageState), лимит в таблице auth_attempt_limits (чистить через python sqlite3, утилиты sqlite3 нет). Превью приложения: прокси 5175→5174 без Origin, `EXPO_PUBLIC_API_URL=http://127.0.0.1:5175 CI=1 npx expo start --web --port 8090 --clear`; с CI=1 перезапускать после правок; mobile/tsconfig.json не коммитить. В скриптах снимков кликать по CSS-селекторам и aria-label, не по тексту.

Учётные записи стенда: +77000000001 владелец, +77000000002 гость, +77000000003 исполнитель (пароль в scripts стенда). База стенда изолирована: outputs/browser-qa/state/v3/d1/. См. [[simple-map-concept]], [[design-system]].

2026-11-15: seed-скрипты требуют `--confirm-isolated`; сессия превью приложения не сохраняется в storageState — входить формой в каждом прогоне и чистить auth_attempt_limits; после входа экран выбора роли (нажать «Владелец»/«Исполнитель уборки»); шторка раскрывается по aria-label «Развернуть панель»; прокси 5175 должен отвечать на OPTIONS и ставить CORS-заголовки.

2026-11-15: событие над картой в приложении проверять вставкой строки в таблицу notifications базы стенда (python sqlite3), приложение опрашивает сервер раз в 15 секунд.
