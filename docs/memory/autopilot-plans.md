2026-11-13 пользователь попросил сделать «Автопилот» платным тарифом, который подключается в профиле и владельцем, и исполнителем. Макеты: https://claude.ai/artifact/9m5qbDBxv2gA4HkzYehkGn. После его «делай» тариф реализован в PR #60 (https://github.com/NIgan1989/ai_arenda/pull/60). Потом добавлены переключатель «Автопилот» и подключение в 3 шага (wizard), пользователь одобрил; слит 2026-11-13 (main b22cdb3), публикация run 43412884125 успешна. Скриншоты: /mnt/project-files/autopilot-plans/.
- Владелец платит 4 900 ₸ в месяц за квартиру, с баланса. Исполнитель платит 1 900 ₸ в месяц, удержанием из выплат. Цены предложил Claude, пользователь их не утверждал. Админ меняет их в «Доход → Тарифы».
- 14 дней бесплатно, 3 дня отсрочки, потом пауза. Пока оплата выключена (plan_charge=0), сервис только записывает, сколько взял бы («в тени»).
- Режим «ИИ» у квартиры (setGuestMode auto) сам запускает подписку. С живой подпиской комиссия с брони обычная 5%, ставка ai_rate_bp действует только без подписки.
- Код: lib/autopilot-plans.ts, миграция 0046. Исполнитель: правила в таблице cleaner_autopilot, ИИ сам принимает предложения в dispatch.
- QA-стенд после перезапуска: `node scripts/start-browser-qa.mjs`. В его базе не хватало миграций 0041–0045, их пришлось применять вручную через node:sqlite.
