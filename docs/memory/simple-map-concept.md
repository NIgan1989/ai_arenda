2026-11-13 пользователь назвал мобильную версию перегруженной, попросил минимум действий и всё вокруг карты; алгоритмы и ИИ-администратор остаются. Выбрал вариант 1 «Только карта» (макет: https://claude.ai/artifact/4iusryG1SBjyuLufPSQ8Ut, копия и снимки этапов в /mnt/project-files/simple-map/). Этапы шли отдельными PR со снимками, каждый слит после «сливай» пользователя; этап 5 слит 2026-11-13 (main 8d99ebe).

Этап 1 (каркас) — PR #79. Сайт ≤700px: `components/map-shell.tsx` держит карту, разделы — шторкой; переходы через `goWorkspace` (`lib/workspace-go.ts`); `map-chrome.tsx` — аватар и чаты. Приложение: MapHome всегда смонтирован, страницы в `s.pageSheet`. `lib/ai-line.ts` должен быть без импортов.

Этап 2 (гость) — PR #80. `lib/guest-trips.ts` (guestTrips, guestSteps, guestStep). «Мои брони · N» открывает брони гостя на карте; главная кнопка брони = ближайший шаг (`onProcess(kind,id,step)` → `runGuestStep`); `checkin-guide.tsx`; результаты поиска списком.

Этап 3 (владелец) — PR #81. `lib/owner-steps.ts` (`runOwnerStep`), `lib/property-hub.ts`. Жильё на карте = карточка с вкладками «Сегодня / Календарь / Цена / Настройки»: `components/property-hub.tsx`, `mobile/src/FlatHub.tsx`.

Этап 4 (исполнитель) — PR #82 (main 59dfefd). `lib/job-steps.ts` (cleanerStep, ownerJobStep, cleanerLine; `runJobStep`). Шторка исполнителя начинается с «Мой день», главная кнопка задания = шаг или «Маршрут до жилья».

Этап 5 (меню) — PR #83. `account-control.tsx` и `mobile/src/AccountControl.tsx`: короткое меню, строки «Профиль / Надёжность / Тариф и автопилот / Настройки / Данные и безопасность» открывают свои экраны (`view`). Из разделов убраны «Мои объекты» (владелец) и «Найти задания» (исполнитель). В приложении счётчик непрочитанных на кнопке чатов.

Не сделано, можно предложить: перенаправление старых адресов страниц на карту, убрать чипы-ссылки под строкой ИИ, заголовок шторки «Сводка» в приложении, проверка на настоящем телефоне.
