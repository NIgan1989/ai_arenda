2026-11-14 пользователь спросил, как не давать гостю и другим участникам держать процесс (галочка «автопредупреждение», напоминания или ИИ следит сам) во всех процессах. Разбор в Claude Doc https://claude.ai/artifact/JkYCUH8ZxyTzt8MtJjty49.

Что уже есть в коде: lib/administrator.ts `planAdministrator` строит задачи со сроком для всех ролей, напоминает за leadMinutes (60) и повторяет каждые repeatMinutes (60), настройки в lib/assistant.ts. Сам ИИ действует только: заявка истекает через 15 мин (administrator-runtime.ts), предложение уборки 15 мин, назначение из откликов через 15 мин, просроченная уборка ([[overdue-cleaning-pr74]], [[unclaimed-cleaning-pr97]]), автоприёмка отчёта 1 ч.
Пробелы: нет кнопки «Опаздываю»; неоплаченная бронь держит жильё до заезда; неявка гостя и невыезд только напоминания; при истёкшей заявке гостю не предлагаются похожие варианты.

Предложено (карточка решения): 1) напоминания + «Опаздываю»; 2) ИИ действует сам по лестнице «напомнить → спросить → действовать → передать человеку»; 3) рекомендовано: сочетание с рейтингом [[algorithms-plan]] (рейтинг надёжности). Пользователь выбрал 3 (сочетание).
