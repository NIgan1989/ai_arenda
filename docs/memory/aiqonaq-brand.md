2026-11-14 пользователь одобрил название «AiQonaq» (қонақ = гость, «Ai» = ИИ) и из трёх направлений выбрал **«Шаңырақ»**: купол юрты из линий с золотыми лучами, круг раскрывается в карту; индиго остаётся, добавлено золото. Превью направлений: https://claude.ai/artifact/Knayyo8dofLu1tK675Zvbb. Снимки и ролики реализации: `/mnt/project-files/aiqonaq-brand/impl/`.

**PR #99** слит и опубликован 2026-11-14 (main afb4ddb). Сборка Android проверена на Limrun: значок и имя AiQonaq, заставка рисуется, название на входе. Найденный дефект (после заставки на экране входа белые значки строки состояния: Android возвращает их, когда размонтирован последний StatusBar) исправлен в **PR #100**, слит 2026-11-14 (main ddb59d2), сборка № 255 проверена: StatusBar стоит один раз в корне `mobile/App.tsx`. Метки и шторку на эмуляторе не проверить: на бою нет тестовых учётных записей. Limrun может кешировать APK по адресу: добавлять `?build=N`.

Правило, заявленное пользователю: орнамент одной тонкой линией только на шторке, метке и знаке ожидания; карточки, списки и чаты чистые.

Как устроено:
- `lib/brand.ts`: название, геометрия купола, буквы контурами, орнамент. Картинки делает `node scripts/build-brand-assets.mjs` (`public/`, `mobile/assets/brand/`, `app/brand-images.css`). Руками картинки не править. `tests/brand.test.mjs` следит за согласованностью.
- Заставка: `components/entry-splash.tsx` (HTML и CSS до загрузки React), `mobile/src/EntrySplash.tsx` (в приложении нет react-native-svg: View и PNG).
- Знак ожидания: `components/thinking.tsx` + `app/loader.css`, `mobile/src/Thinking.tsx`.
- Технические имена не менялись: схема `aiarenda`, пакет `app.aiarenda.assistant`, slug `ai-arenda`, `ai-arenda.apk`, ключ `ai-arenda-entry`, домен и Worker.

**Why:** бренд должен выглядеть одинаково на сайте и в приложении, знак рисуется из одних чисел.

Аватар для Telegram (2026-11-18): `/mnt/project-files/aiqonaq-brand/telegram/` (1024 и 640, квадрат без скругления, знак scale .62 под круглую обрезку), сделан из `badgeSvg` без изменений в репозитории.

**How to apply:** менять знак только через `lib/brand.ts` и пересборку картинок. В Chromium переход не стартует с места, где элемент оставила анимация: части заставки уводить тоже анимацией. Для снимков веб-превью приложения подменять `brand/*.png` на `@3x` (dev-сервер отдаёт только 1×). См. [[loading-splash-pr26]], [[qa-stand]], [[design-system]], [[map-motion-pr14]].
