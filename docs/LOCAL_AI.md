# Локальный ИИ

Сервер приложения поддерживает Ollama. Ключ платного API не требуется. Модель генерирует справочные ответы; операции с квартирами, заявками и уборками выполняются проверяемыми методами сервиса. Свободный текст пока не заменяет формы и подтверждения.

## Windows

1. Установите Ollama с https://ollama.com/download/windows.
2. В папке проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local-ai.ps1 -Pull
npm run dev
```

Скрипт запускает Ollama в фоне на 127.0.0.1:11434, отключает облачные функции для запущенного им процесса, скачивает qwen3:1.7b и сохраняет локальные настройки в игнорируемый .sites-runtime/local-ai.json. При уже запущенном Ollama настройки его процесса не меняются. После перезагрузки запустите скрипт снова без -Pull. Модель хранится в пользовательском каталоге Ollama, в GitHub не отправляется.

На компьютере с 7 ГБ памяти выбрана компактная модель; качество и скорость ограничены оборудованием. Первая генерация загружает модель в память. Контекст ограничен 2048 токенами, ответ — 256 токенами. При недоступности модели приложение возвращает сценарную подсказку с сообщением о недоступности; автоматического перехода на платный API нет.

## Сервер

На отдельном сервере установите Ollama, скачайте модель и задайте серверные переменные AI_PROVIDER=ollama, OLLAMA_BASE_URL и OLLAMA_MODEL. Конфигурация .sites-runtime используется только npm run dev. Для production переменные должны быть заданы на хостинге. Адрес 127.0.0.1 означает машину, на которой работает backend; облачный Worker не видит модель на вашем ноутбуке. Используйте доступную backend приватную сеть или защищённый шлюз. Не открывайте Ollama напрямую в интернет.

POST /api/chat требует действующий аккаунт и разрешённую роль. История ограничена текущим пользователем и ролью. Сервер не добавляет к запросу базу квартир, адреса объектов, данные аккаунтов или полномочия выполнять SQL; сведения, которые пользователь сам напишет в чате, могут попасть в запрос. Контакты в тексте маскируются, но пользовательский текст и краткая история всё равно обрабатываются настроенным сервером Ollama. Языковая модель может ошибаться.

Проверка интеграции: node --test tests/service.test.mjs. Тесты подменяют сетевой ответ, проверяют выбор Ollama и возврат сценария без платного запроса при сбое. Для проверки реальной модели нужен запущенный Ollama с загруженной моделью.

Локальная проверка 20 октября 2026: Qwen3 1.7B через Ollama 0.40.6, authenticated POST /api/chat вернул HTTP 200, mode=local-model, ответ за 17,5 секунды на CPU компьютера с 7 ГБ памяти. Это единичная проверка, а не гарантия скорости под нагрузкой.
