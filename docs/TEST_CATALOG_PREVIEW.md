# Учебный просмотр каталога

Обновление: стандартный изолированный стенд теперь поддерживает полный учебный цикл без обязательных проверок личности и SMS. Подготовка, ограничения и порядок тестирования описаны в [QA_WORKFLOWS.md](QA_WORKFLOWS.md). Режим только просмотра ниже остаётся запасным поведением, если политика допуска включена; её включение через интерфейс учебного стенда закрыто.

30 октября 2026: на изолированном QA-стенде все 901 учебный объект скрылись после включения обязательной проверки владельца и телефона. Проверки не проходились, и действующий фильтр допуска корректно исключал их из обычного каталога.

Теперь только серверная конфигурация `TEST_DATA_ONLY=1` разрешает предварительный просмотр опубликованных синтетических объектов с описанием, начинающимся с `СИНТЕТИЧЕСКОЕ ОБЪЯВЛЕНИЕ`. Обычные объекты по-прежнему проходят прежний фильтр. Клиентские поля запроса не включают этот режим. В рабочей конфигурации поведение каталога не меняется.

Дополнительно возвращаемые учебные объекты имеют `test_preview=1`, если не проходят обычный фильтр. В списке видна пометка «Учебный просмотр · без бронирования», кнопки заявки отключены. Серверная проверка создания брони сохраняется независимо от интерфейса. Записи проверки личности, подтверждения телефона и правила платформы не изменяются.

На карте гостя список открывает поиск жилья даже из режима текущего процесса. Автоматический переход гостя от поиска к ближайшей брони убран; процесс по-прежнему доступен отдельной кнопкой. Ошибка загрузки предлагает повтор, а пустой поиск — сбросить условия и показать всё жильё.

В браузере проверено отображение 10 квартир Астаны. Тест `test-catalog-preview.test.mjs` проверяет изоляцию, невозможность включения клиентским полем, запрет бронирования и исключение обычных недопущенных объектов. Полная проверка: `outputs/guest-catalog-verification.log`.
