# Программная политика AI администратора

Обновлено 29.10.2026.

AI администратор включён по умолчанию. Пользовательского переключателя, выбора модели и страницы настроек больше нет. Старое поле aiConsent, включая false, не влияет на доступность. Старые ссылки /workspace/{role}/settings перенаправляются на карту; API изменения настроек после авторизации возвращает 410.

Политика определена в lib/assistant.ts: proactive, напоминание за 60 минут, повтор через 60 минут, тихие часы выключены. Сохранённые assistant_preferences не переопределяют эту политику. Правила контролируют процессы без вызова модели при каждом обновлении карты. Сохраняются авторизация, бюджет и частота запросов, изоляция тестового стенда, полномочия объектов, подтверждение финансовых и фактических действий, отдельное согласие на передачу геопозиции.

История администратора доступна в разделе «Чаты» и в отдельном окне по нажатию подвижного логотипа. Чтение истории не вызывает модель. История и курсор пагинации проверяются по аккаунту и роли. Личные сообщения и фотографии из обсуждений участников не передаются модели.
