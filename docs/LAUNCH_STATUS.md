# Общие настройки запуска

Обновлено 11 ноября 2026. Рабочий сайт: https://ai-arenda.ai-arenda-kz.workers.dev.

| Направление | Состояние | Что осталось |
|---|---|---|
| Хостинг и HTTPS | Cloudflare Workers и D1 работают | Следить за бесплатными квотами и производительностью при росте |
| База и учётные записи | Сохранён администратор, каталог пуст | Не возвращать старые объявления из резервных копий |
| Авторизация и права | Единый аккаунт, серверные проверки ролей и админский allowlist | Проверить вход и восстановление на физических устройствах |
| Допуск | Для владельцев и исполнителей включена ручная проверка | Определить рабочий порядок рассмотрения заявок |
| OpenAI | Серверное подключение и ограничения операций есть | Контролировать API-бюджет и реальные сценарии поддержки |
| Планировщик | Работает независимо от компьютера | Настроить внешнее оповещение об отказах |
| Резервирование | Полный зашифрованный облачный экспорт восстановлен в отдельной D1 и сверен | Регулярные независимые копии и повторные проверки восстановления |
| Web Push | VAPID, очередь, отзыв подписок, настройки устройств | Проверить получение на реальных Android/iPhone с разрешениями ОС |
| Подтверждение телефона | Не подключено | Выбрать и настроить SMS-провайдера; сохранение номера не подтверждает владение |
| Платежи | Учёт фактических расчётов есть, автоматического приёма нет | Рабочее подключение платёжного провайдера, проверка оплаты и возвратов |
| Медиа | Фотографии пока хранятся в D1 | При росте перенести в файловое хранилище и включить его в резервирование |
| Поддержка и документы | Страницы и обращения есть | Заполнить реквизиты, контакты и окончательные условия сервиса |
| Адрес сайта | Работает workers.dev | Собственный домен по желанию, для пилота не обязателен |
| Нативное приложение | Исходники есть | Отдельная сборка, Expo push и выпуск не выполнялись |

Healthcheck может быть зелёным после разовой успешной резервной копии. Это не означает, что регулярное внешнее резервирование уже автоматизировано. Его отметка устаревает через 48 часов.

## Дизайн

Редактируемый Figma-файл: https://www.figma.com/design/e1uWm7axJ0ddYYlAEi1xfS.

В файле подготовлены брендовые переменные и типографика, 19 общих веб-экранов и 2 мобильных экрана. Дальнейшие вызовы остановлены квотой Figma Starter. Полный перенос и заключительная визуальная проверка Figma остаются незавершёнными.

Полный локальный просмотр: `/design-review.html`. Каталог содержит 71 экран в двух размерах, с вымышленными примерами. Это самостоятельные дизайн-макеты, не интерфейс действующих процессов. В рабочее приложение перенесены главная с поиском, навигация кабинетов, общие формы и карточки, оформление бронирования, редактор объекта и отчёт уборки. Подробный статус и проверки — в INTERFACE_RELEASE.md. Остальные специальные компоновки ещё не перенесены.

Исходники и перечень экранов: `design/`. Создание просмотра: `node scripts/build-design-preview.mjs`. Ни макеты, ни скрипты не читают профили, переписку, реквизиты или пароли из рабочей базы.
