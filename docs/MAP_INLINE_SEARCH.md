# Поиск прямо на карте

Верхнее поле карты применяет условия поиска, не открывает диалог администратора и не вызывает модель. Лого остаётся единственным входом в помощь администратора. Доступные кнопки: «Карта», «Мой процесс», «Список». Список открывается только явным нажатием своей кнопки. Выбор круглой ценовой метки раскрывает карточку, а кластер сначала приближает группу объектов.

По умолчанию нижняя панель свёрнута до полоски высотой 28 px — около 3% экрана высотой 844 px. Область нажатия ручки остаётся 44 px. Открытие: ручка, перетаскивание вверх, клавиатурные стрелки или метка объекта. Escape сворачивает панель и возвращает карту. Содержимое скрытой панели не попадает в клавиатурную навигацию. Карта учитывает реальную высоту панели при размещении точки и маршрута.

Парсер понимает ограниченный набор выражений: город, «2-комнатная» (от двух комнат), «для 3 гостей», «до 20 тысяч», «сегодня/завтра на 2 суток/3 часа», явный интервал «с 2026-11-01 по 2026-11-03». Время — Казахстан, UTC+5. Применённые условия показаны над картой. Неподдержанные пожелания вроде вида из окна не считаются применёнными фильтрами.

Без дат доступность не обещается: показывается предложение выбрать заезд и выезд. С датами используется существующий серверный поиск с проверкой занятости, уборок и внешних блокировок. При неверном явном интервале прежние даты сбрасываются. Реальная бронь по-прежнему проходит отдельный серверный расчёт и допуск.

«Рядом со мной» запрашивает положение браузера и ограничивает результаты приблизительным радиусом 5 км, затем сортирует по расстоянию. Точки публичного жилья приблизительные; адреса не раскрываются. Если положение недоступно, интерфейс сообщает, что ищет по городу. При конфликте явно указанного города и геолокации сохраняется указанный город, радиус не применяется. Координаты не передаются модели.

Проверка: `outputs/map-inline-search-verification.log` — 175 бизнес-тестов, 37 HTTP-тестов, схема, типы, сборка. В браузере запрос «Найди в Астане до 10000» дал три метки; кластер раскрылся в ценовые метки, нажатие открыло карточку без диалога администратора.
