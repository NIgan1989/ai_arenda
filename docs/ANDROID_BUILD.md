# Приложение для Android: тестовая сборка

Обновлено 12 ноября 2026 года. Это сборка для пилота, а не для Google Play.

## Где скачать

Постоянная страница: <https://github.com/NIgan1989/ai_arenda/releases/tag/android-latest>, файл `ai-arenda.apk`.

Прямая ссылка на файл: <https://github.com/NIgan1989/ai_arenda/releases/download/android-latest/ai-arenda.apk>.

Страница появляется после первой успешной сборки в ветке `main`. На ней указаны номер сборки, дата и адрес сервера. Файл заменяется после каждого изменения приложения в `main`: папки `mobile/` или общих правил в папке `lib/`. Если репозиторий закрытый, для скачивания нужен вход в GitHub с доступом к нему.

На эту страницу попадают только сборки ветки `main`. Сборка из pull request или из другой ветки туда не попадает. Её можно взять так: вкладка Actions, «Build Android test app», нужный запуск, раздел Artifacts, архив `ai-arenda-android` (внутри тот же `ai-arenda.apk`). Архив хранится 30 дней.

Собрать вручную: Actions, «Build Android test app», «Run workflow». В списке «Use workflow from» оставьте `main`, тогда файл на странице заменится. Если выбрать другую ветку, сборка пройдёт, но файл будет только в Artifacts этого запуска. Если сборка идёт дольше 45 минут, она останавливается с ошибкой.

## Как установить

1. Откройте ссылку на телефоне с Android 7.0 или новее и скачайте `ai-arenda.apk`.
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника (браузер или «Файлы»): разрешите.
3. Если Play Защита предупредит о неизвестном приложении, подтвердите установку.
4. Войдите тем же номером телефона и паролем, что на сайте. Данные общие с сайтом.

Обновление: скачайте новый файл и установите поверх старого. Вход сохраняется.

## Ограничения

- Подпись. Файл подписан общим отладочным ключом из шаблона React Native (`android/app/debug.keystore`). Этот ключ есть у всех, поэтому ставьте приложение только с этой страницы. В Google Play такую сборку не примут. Когда появится свой ключ подписи, тестовую версию придётся удалить и поставить новую.
- Проверка. Автоматически проверяется только то, что файл собрался, подписан и содержит правильный адрес сервера. На телефонах сборку нужно проверять вручную; на 11.11.2026 таких проверок ещё не было.
- Сервер. Приложение работает с <https://ai-arenda.ai-arenda-kz.workers.dev>. Другой адрес задаётся переменной репозитория `ARENDA_PUBLIC_URL` (она же используется при публикации сайта).
- Устройства. Только телефоны Android на процессорах ARM. Эмуляторы x86 и iPhone не поддерживаются: для iPhone нужен аккаунт разработчика Apple.
- Значок. Своего значка у приложения пока нет, на телефоне будет стандартный зелёный робот Android. Чтобы заменить, добавьте поле `icon` в `mobile/app.json`.
- Уведомления. Push-уведомления на телефон не подключены.

## Как устроено

Файл `.github/workflows/android.yml`. Аккаунт Expo/EAS и секреты не нужны.

Сборка запускается сама, когда в `main` или в pull request меняется то, из чего собирается приложение:

- папка `mobile/`;
- папка `lib/`: общие с сайтом правила, которые приложение берёт оттуда (разбор запроса гостя, карточка «Сейчас», правила аренды и объявлений);
- `design/tokens.json`: из него получается `mobile/src/tokens.ts`;
- `scripts/check-mobile-release.mjs` и сам файл сборки.

Изменения в остальных папках сборку не запускают: в приложение они не попадают.

Шаги сборки:

1. `npm ci` в `mobile/`.
2. `node scripts/check-mobile-release.mjs --profile preview` проверяет `app.json` и адрес сервера.
3. В `app.json` на сборочной машине подставляется номер сборки (`versionCode` и версия вида `0.1.0-pilot.N`). В репозиторий это не записывается.
4. `npx expo prebuild --platform android --no-install` создаёт папку `mobile/android`. Она не хранится в репозитории.
5. `./gradlew assembleRelease` собирает APK для `arm64-v8a` и `armeabi-v7a`.
6. Файл сохраняется как артефакт `ai-arenda-android`. Если собиралась ветка `main` (после изменения или вручную), отдельное задание кладёт его в предварительный релиз `android-latest`. Только это задание может изменять репозиторий. Запуски из pull request и из других веток работают только на чтение, и это задание в них пропускается.

Собрать на своём компьютере (нужны Node.js 24, JDK 17 и Android SDK):

```sh
cd mobile
npm ci
npx expo prebuild --platform android --no-install
cd android
EXPO_PUBLIC_API_URL=https://ai-arenda.ai-arenda-kz.workers.dev ./gradlew assembleRelease
```

Готовый файл: `mobile/android/app/build/outputs/apk/release/app-release.apk`.
